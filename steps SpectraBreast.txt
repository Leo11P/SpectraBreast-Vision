RUNNING THE PIPELINE
--------------------------------------------------------------------------------

# Activate the environment (if not already active)
cd ~/SpectraBreast-Vision
source .venv/bin/activate

# Full end-to-end (vision + registration)
spectra full --config configs/default.yaml

# Vision only (3D reconstruction + ArUco)
spectra vision --config configs/default.yaml

# Registration only (HSI -> mesh, AFTER vision has already run)
spectra registration --config configs/default.yaml

# Process a different sample without editing the YAML
spectra full --config configs/default.yaml --sample SAMPLE2_iphone

# Change mode without editing the YAML
spectra full --config configs/default.yaml -s registration.mode=roi

## BE AWARE, IF YOU HAVE ALREADY DONE THE VISION PART ON A SAMPLE, THEN AUTOMATICALLY THE PIPELINE SKIP THIS STAGE BY DEFAULT !
## YOU CAN FORCE IT BY 
# Force re-running vision (even if already done)
spectra full --config configs/default.yaml --force-vision

# Validate config and paths without executing anything
spectra full --config configs/default.yaml --dry-run







OUTPUT — WHERE FILES ARE SAVED
--------------------------------------------------------------------------------

All outputs go to RESULTS/<sample_name>/

RESULTS/
└── SAMPLE1_iphone/
    │
    ├── vision/                              <- Vision stage outputs
    │   ├── cloud.ply                        colored 3D point cloud (open with CloudCompare)
    │   ├── cloud.npz                        3D point cloud in numpy format
    │   ├── surface_mesh.ply                 3D surface mesh  <- used by Registration
    │   ├── aruco_markers_3d.json            3D positions of ArUco markers  <- used by Registration
    │   ├── surface.ply                      surface point cloud
    │   ├── surface.npz                      surface in numpy format
    │   ├── camera_poses_output_frame.npy    camera poses
    │   ├── reconstruction_metadata.json     run metadata (timing, point counts, etc.)
    │   ├── run.yaml                         config used for this run
    │   ├── aruco_detections/
    │   │   ├── json/                        per-image ArUco detections
    │   │   └── annotated/                   images with ArUco markers drawn
    │   └── rerun/
    │       └── spectra.rrd                  Rerun recording for interactive 3D viewing
    │
    └── registration/                        <- Registration stage outputs
        ├── spectral_pointcloud_SAMPLE1_iphone.ply          spectral point cloud (CloudCompare)
        ├── spectral_pointcloud_SAMPLE1_iphone_xyz.bin      XYZ coordinates (numpy memmap)
        ├── spectral_pointcloud_SAMPLE1_iphone_spectra.bin  spectra (numpy memmap)
        ├── spectral_pointcloud_SAMPLE1_iphone_wavelengths.npy  wavelengths in nm
        ├── SAMPLE1_iphone_registration_errors.xlsx         Excel report with 2D/3D errors
        ├── SAMPLE1_iphone_registration.png                 HSI + render overlay with ArUco
        ├── SAMPLE1_iphone_coverage.png                     HSI -> mesh coverage map
        ├── SAMPLE1_iphone_render_pc_topview.png            orthographic top-view render
        └── SAMPLE1_iphone_render_pc_turbo.png              TURBO colormap render

For BATCH mode, additionally:
    RESULTS/
    └── _batch/
        └── batch_summary.xlsx               summary of all processed samples

For SWEEP mode, additionally:
    RESULTS/SAMPLE1_iphone/registration/
        └── SAMPLE1_iphone_sweep_resolution_summary.xlsx  comparison across resolutions
